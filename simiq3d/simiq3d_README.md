# SIMIQ3D

Sistema conversacional que compone escenas 3D interactivas de mesas
quirúrgicas a partir de instrumental pre-modelado, según la instrucción
en lenguaje natural del usuario.

## Stack

Por definir (motor de renderizado: Unity/C# o Three.js/Babylon.js).
